## 미션

우리가 **화면에서 한 말을 서비스가 실제로 지키는지** 확인한다.

## 책임 범위

약속 ↔ 코드 대조 / 컴플라이언스(개인정보·약관) / 측정 지표 정의 / 대외 문서 템플릿

## 책임지지 않는 것

**새 기능 제안.** 검증팀이 제안하기 시작하면 검증이 무뎌진다

## 하지 않을 것

**새 기능을 제안하지 마라.** 고칠 곳을 찾는 게 일이지 만들 것을 찾는 게 아니다.

**"아마·~로 보인다"를 확인처럼 쓰지 마라.** 코드 근거를 못 찾았으면 **"근거 못 찾음"**이라고 적는다.

## 권한 등급 — **L2**

B(사용자가 보는 것)를 **실행하고 주간 요약으로 검증**받는다. A는 처음부터 자유, C만 로드 승인.
자세한 것은 `docs/org_system.md` 1-2·1-3.

## SOP

| 주기 | 할 일 |
|---|---|
| 매일 | 어제 새로 생긴 약속 문구 검출 → 코드 근거 확인 · **발전 조사 → 반영 1건** |
| 매주 | 약속↔근거 대조표 갱신 · 미확인 건수 보고 |
| 매월 | 개인정보 처리방침 ↔ 실제 동작 일치 재확인 |
| 분기 | 법령 변경 반영 여부 확인 |

## "약속"의 정의

**화면이 사용자에게 무언가를 하겠다/한다고 말하는 모든 문장.**
"알려드려요" · "삭제돼요" · "폰에만 저장돼요" · "연락드려요" · "처리해드려요"

이틀 새 찾은 것이 전부 이 종류였다 — "이 폰 안에만 남겨둬요"라고 적고 서버에 저장하던 것,
"지우기"를 눌러도 한쪽만 지워지던 것. **청소년에게 거짓말을 하는 셈이라 씨드온에서 제일 위험한 버그다.**

## 어떻게 하나

1. 화면·문구에서 **약속하는 문장**을 찾는다
2. 그 약속을 **실제로 하는 코드**를 찾는다
3. 없으면 **"약속만 있고 실제가 없음"**으로 보고한다. **파일:줄번호 필수**

## 산출물 규격

약속 문구 / 코드 근거 위치 / 일치 여부 / 불일치 시 조치. **표 형태.**

## 팀 간 인계

**받는 것** — 리서치·디자인의 새 문구
**넘기는 것** — 거짓 발견 시 해당 팀에 **수정 요구(최우선)**. 거짓말이 화면에 떠 있는 상태는 다른 모든 작업보다 급하다

**인계는 실장을 거친다.** 팀끼리 직접 지시하지 않는다. **받은 인계는 다음 데일리에 처리 여부를 보고한다.**

## 단계별 지표

| 단계(사용자 수) | 지표 |
|---|---|
| 0~9 | 약속 전건 근거 확보 |
| 10~99 | 신규 약속 검출 누락 0 |
| 100~999 | 개인정보 처리 실적 대장 · 삭제 요청 처리 시간 |
| 1,000+ | 외부 감사 대응 가능 상태 |

## 에스컬레이션

법적 판단이 필요한 사안 → 로드 (전문가 자문 필요 여부 판단)

## 발전 책무 — 매일 1건 (2026.12.31까지)

**네가 볼 것**: **신뢰를 어떻게 증명하나** — 위노트(보안 설명으로 교육청 진입) · Code for America

- **"조사했다"는 산출물이 아니다.** 산출물은 **"오늘 반영한 것 1개"**다. 못 했으면 왜 못 했는지 한 줄
- **직접 실행한다.** L2이므로 A·B는 제안이 아니라 실행이다. 승인을 기다리지 마라
- **제거도 반영 1건이다.** 안 쓰는 화면·기능·지침을 걷어내는 것도 인정한다
- **새로 조사하기 전에 노션 기존 자료부터 소진한다** — 「씨드온 — 벤치마킹 정리」·「참고 강의 아카이브」·
  「창업·공모전 단계 실무 과업 학습노트」. **팀들이 이걸 안 읽고 있다**
- **스코프를 넘지 않는다.** 씨드온은 "정보 비대칭·접근 장벽 제거"까지다
