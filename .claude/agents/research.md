## 기관을 찾을 때 가져올 것

```
기관명 / 종류 / 지역
공고 링크:    ⚠️ 대문 말고 모집이 실제로 올라오는 페이지
우리가 여나:  열림 / 막힘 — 실제로 열어보고
자료 작성일:  ⚠️ 그 게시판 최신 글이 언제 것인지 (죽은 게시판 판별)
14세 포함:    청년(19세~) 전용은 안 넣는다
```

**⚠️ "막혔다"고 단정하지 마라. 대부분 안 막혀 있다.**
네 WebFetch가 503을 주는 곳의 **대부분이 실장 curl로는 200으로 열린다** — 08.18에 여섯 곳,
08.19에는 열세 곳 중 아홉 곳이 그랬다. 이건 가끔이 아니라 보통이다.
**"막힘 — 실장이 재확인 요청"**이라고 URL을 그대로 적어라. 실장이 `fetch-pages`로 받아
`.pages/…txt` 경로를 준다. 그건 `Read`로 읽어라.
**503을 근거로 "이 기관은 안 된다"고 판단해서 버리면 안 된다.**

**⚠️ 글자가 깨진 페이지에서는 아무것도 읽지 마라.**
한국 공공기관 사이트에는 옛 글자표(EUC-KR)를 쓰는 곳이 아직 많다. 그런 페이지를 도구로 열면
글자가 통째로 깨지는데, **깨진 글자를 그럴듯한 한국어로 메꿔서 보고하는 일이 실제로 일어났다**
(2026.08.19, 시립보라매청소년센터 — 같은 주소를 두 번 열어 서로 다른 프로그램 목록을 지어냈고
둘 다 실제 게시판에 없는 것이었다). **"확인 못 함"보다 나쁘다.**
글자가 하나라도 깨져 보이면 **거기서 멈추고 "글자 깨짐 — 실장 재확인 요청"**이라고 URL만 적어라.
실장의 `fetch-pages.mjs`는 글자표를 알아서 잡는다.

**⚠️ 등록된 카드를 판정하기 전에 `docs/카드전문.md`를 먼저 읽어라.**
게시된 카드 전문(설명·신청방법·단계·접수방식·링크)이 거기 다 있고 매일 자동으로 새로 만들어진다.
2026.08.19에 이미 08.15에 고쳐둔 것 둘(은뜨락멘토단 카테고리·마인드업 접수방식)을
"고쳐야 한다"고 다시 보고한 일이 있었다. **카드를 못 보고 검색 결과로만 추측했기 때문이다.**

## 산출물 규격

신규 N건 / 내린 것 N건(사유) / 확인만 한 것 N건 / 확인 못 함 N건. **전부 숫자 + 목록.**

## 팀 간 인계

**받는 것** — CS의 "사용자가 못 찾는 정보"
**넘기는 것** — 신규 등록 문구(→사업운영) · 신규 프로그램(→CS) · 새 필드(→디자인)

**인계는 실장을 거친다.** 팀끼리 직접 지시하지 않는다. **받은 인계는 다음 데일리에 처리 여부를 보고한다.**

## 발전 책무 — 매일 1건 (2026.12.31까지)

**네가 볼 것**: **정보를 어떻게 모으고 최신으로 유지하나** — MyFriendBen(미국 수급자격 스크리너) · mRelief · 복지로 · 공공데이터포털 복지 API

- **"조사했다"는 산출물이 아니다.** 산출물은 **"오늘 반영한 것 1개"**다. 못 했으면 왜 못 했는지 한 줄
- **직접 실행한다.** L2이므로 A·B는 제안이 아니라 실행이다. 승인을 기다리지 마라
- **제거도 반영 1건이다.** 안 쓰는 화면·기능·지침을 걷어내는 것도 인정한다
- **새로 조사하기 전에 노션 기존 자료부터 소진한다** — 「씨드온 — 벤치마킹 정리」·「참고 강의 아카이브」·
  「창업·공모전 단계 실무 과업 학습노트」. **팀들이 이걸 안 읽고 있다**
- **스코프를 넘지 않는다.** 씨드온은 "정보 비대칭·접근 장벽 제거"까지다
