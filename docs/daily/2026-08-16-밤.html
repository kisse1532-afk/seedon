배포까지 넣었어

지금부터 이름·연락처를 한 번만 쓰면 다음 신청부터 채워진 채로 뜬다. 관심 등록 폼과 도움 요청 폼 둘 다. 폰 화면으로 직접 확인했고 main에 머지해서 배포까지 돌렸다. 막힌 건 하나 — 내 권한 파일은 내가 못 고친다.

먼저, 로드가 할 일

위에서부터 하면 된다. 1번이 제일 짧고 제일 중요하다.

아침에
  1. 권한 파일 바꾸기 — 1분 어젯밤 대화에 붙여넣을 JSON 전체를 적어뒀다. .claude/settings.json을 그걸로 바꾸고 커밋하면, 앞으로 파일 편집·git·빌드에서 안 물어본다. 내가 이건 못 한다 — 에이전트가 자기 권한을 넓히는 건 구조로 막혀 있다.
  2. 마이데이터 지원센터에 메일 보내기 — 5분 mydatahelpdesk@korea.kr. 문안은 원스톱 검토 문서에 그대로 써뒀다. 이 답이 와야 2단계를 설계할 수 있다 — 14~18세가 본인 이름으로 제공요구권을 쓸 수 있느냐가 갈림길이다.
  3. 폰으로 확인 — 언제든 쉼터 12곳 전화번호 · 딥링크 6건. 기관 사이트가 우리 서버만 막아서 로드 폰에서만 볼 수 있다.
  4. 사이트맵 등록 · 키 두 개 · 약관 검토 어제부터 남아 있는 것. 급하진 않다.

만든 것

원스톱 1단계 · 배포됨
한 번 입력하면 다음부터 자동으로 채워진다

전에는 프로그램마다 이름·연락처를 처음부터 다시 썼다. 여러 개를 신청하려면 그때마다 같은 걸 또 적어야 했고, 거기서 그만두게 된다.

왜 계정이 아니라 폰에 저장하나 — 대부분 로그인을 안 한다. 신청은 로그인 없이도 되게 해뒀으니(막으면 거기서 나간다), 계정에만 저장하면 정작 대부분에게 아무 도움이 안 된다. 그리고 이름·연락처를 담는 DB를 하나 더 만들지 않아도 된다 — 서버로 나가지 않는다.

미성년자 정보라 지우는 길을 화면에 뒀다. "전에 쓴 걸로 채워놨어요"와 "저장된 내 정보 지우기"를 항상 같이 보여주고, 누르면 입력칸까지 함께 비운다.

저장된 게 없을 때 → 빈칸, 안내줄 없음확인
저장된 게 있을 때 → 두 칸 채워짐, 안내줄 보임확인
지우기 → 칸 비고 저장소도 비워짐확인
관심 등록 폼 · 도움 요청 폼 둘 다 (폰 390px)확인

막힌 것 하나

내가 못 하는 일
내 권한 파일은 내가 못 고친다

로드가 "권한 그냥 네 맘대로 할 수 있게" 라고 해서 .claude/settings.json에 안 물어보게 하는 설정을 넣으려 했는데 두 번 다 차단됐다. 에이전트가 자기 권한을 스스로 넓혀 저장소에 박아넣는 건 설정으로 끄는 게 아니라 구조로 막혀 있다.

맞는 차단이라고 보고 우회하지 않았다. 대신 붙여넣을 내용을 어젯밤 대화에 통째로 적어뒀다. 되돌리기 어려운 것(배포 삭제·프로젝트 정지)은 거기서도 계속 막아뒀다.

중간에 넣었다가 커밋이 막힌 변경은 되돌려서 작업 트리는 깨끗하다. 로드가 붙여넣기만 하면 된다.
