# 약속 점검표 — 화면이 한 말과 실제가 같은가

> **왜 이 파일이 있나 (2026.08.18)**
> 사업운영팀이 이틀 동안 찾아낸 것 중 값진 게 전부 같은 종류였다 —
> **화면은 이렇게 한다고 적어놨는데 실제로는 안 하는 것.** 청소년에게 거짓말을
> 하는 셈이라 씨드온에서 제일 위험한 버그다. 그래서 이걸 팀의 주업으로 삼는다.

## 사업운영팀의 목표 — 무엇이 "다 됐다"인가

**화면에 적힌 약속마다 "실제로 그렇게 한다"는 코드 근거가 붙는 것.**
아래 표가 전부 `확인`이 되면 한 바퀴 돈 것이다.

## 어떻게 하나

1. 화면·문구에서 **약속하는 문장**을 찾는다 — 저장한다 / 지운다 / 알려준다 / 연락한다 / 처리한다
2. 그 약속을 **실제로 하는 코드**를 찾는다
3. 없으면 **"약속만 있고 실제가 없음"**으로 보고한다. 파일:줄번호를 반드시 적는다

  2026-08-18에 설문이 막고 있던 것을 찾아 고쳤다. 남은 자리가 있는지 계속 본다
- **관리자 화면에 영원히 비어 있을 구역** — "📮 신청 (관심 등록)"은 로드가 기능을 뺐는데
  화면 구역이 남아 있다. 되돌리기 쉽게 남긴 것이라 지금은 그대로 둔다(이미 정해진 것)
