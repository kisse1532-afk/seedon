어떻게 굴러가나

  1. 팀은 스스로 오늘 할 일을 정한다. 자기 파일에 "제일 오래 안 본 것부터"가 적혀 있어서 실장에게 안 묻는다
  2. 팀에게 쓰기 권한이 없다. 프로그램을 직접 올리거나 코드를 고칠 수 없다 — 실장이 근거를 직접 열어 확인한 뒤 반영한다. 오늘도 "관심 등록이 없다"(로드가 뺀 것)와 "인천 쉼터"(2013년 자료)를 이 단계에서 걸렀다
  3. 막히면 실장이 도구로 뚫어준다. 디자인은 브라우저가 없어 화면 사진을, 리서치는 페이지가 막혀 본문을 파일로 받는다. 오늘 "막혔다"던 6곳이 사실은 다 열려 있었다
  4. 매번 "밖은 어떻게 됐나"를 묻는다. 밖으로 나간 것 / 밖에서 배운 것. "없음"이 이어지면 팀 잘못이 아니라 실장이 안쪽 일만 주고 있다는 신호다
