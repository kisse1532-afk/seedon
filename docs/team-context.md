# 씨드온 — 팀 공통 배경 (모든 부서가 먼저 읽는다)

> 부서 에이전트는 매번 아무것도 모르는 상태로 시작한다. 이 문서가 "지금까지 어디까지 왔는지"를 넘겨주는 인수인계서다.
> 규칙은 저장소 루트 `CLAUDE.md`가 최상위. 이 문서와 다르면 `CLAUDE.md`가 우선.
> 마지막 갱신: 2026.08.16

---

## 1. 씨드온이 뭐 하는 데인가

청소년 지원 정보 플랫폼. **"이미 존재하지만 닿지 않는 지원을, 청소년이 눈치 보지 않고 쓸 수 있게 연결"** 하는 것.

핵심 가설: 교육불평등의 상당 부분은 "기회가 없어서"가 아니라 **이미 있는 제도를 몰라서·번거로워서·낙인이 두려워서** 못 쓰는 것이다.

**우리 역할의 끝**: 정보 비대칭과 접근 장벽 제거까지. 그 뒤 청소년의 삶이 어떻게 되는지는 씨드온 관할이 아니다. 이 선을 넘는 기능을 제안하지 말 것.

**운영**: 로드(한성재) 1인 + AI 부서. 로드는 비개발자다.

---

## 2. 지금 어디까지 왔나 (2026.08.16)

**만들어진 것** — 프로그램 39건 게시, 카테고리 7종, 검색(문장 입력 가능), 신청·관심등록, 도움요청, 북마크, 회원가입(이메일), 마이페이지, 커뮤니티(관리자 작성만), 관리자 화면, 카톡 미리보기 카드.

**품질을 지키는 도구 4개** — 매일 자동으로 돈다.
`check-links`(링크 생사) · `check-programs`(마감·접수방식·기관대문 링크·금액) · `verify-facts`(사업명·금액이 공식 페이지에 실제 있나) · `check-og-logo`(카톡 카드)

**숫자 (2026.08.16)**
```
가입자 3명 (대부분 테스트 계정)
신청 0건 · 도움요청 0건 · 북마크 1건
게시 프로그램 39건
  교육 11 · 경제생활비 9 · 진로 5 · 공모전 5 · 문화체험 4 · 심리상담 3 · 주거 2
```

## 3. 지금 진짜 막혀 있는 것

**제품이 아니라 유입이다.** 기능은 다 만들어졌는데 **청소년이 씨드온을 알게 되는 통로가 하나도 없다.**

청소년은 스스로 이런 서비스를 찾지 않는다. 어른(학교 상담교사·지역아동센터·청소년수련관)을 거쳐야만 닿는다. 그래서 기관 한 곳이 링크를 소개해주는 순간부터 숫자가 생긴다.

**기능을 더 만들어도 이 숫자는 안 움직인다.** 모든 팀은 이걸 전제로 제안할 것.

## 수익 방향 — B2G · 기업 CSR B2B (2026.08.16 로드 지시)

> 로드: *"b2g, csr b2b를 하는 기업을 생각해야 되는 거야."*

씨드온이 돈을 받는 쪽은 **청소년이 아니다.** 청소년에게는 끝까지 무료이고 광고도 없다
(그래야 "눈치 보지 않고 쓸 수 있는 곳"이 된다). 돈은 두 군데서 온다.

| | 누구한테 | 무엇을 팔거나 받나 |
|---|---|---|
| **B2G** | 지자체·교육청·학교·공공기관 | 관내 청소년에게 지원제도를 닿게 하는 일. 위탁·용역·구독 형태 |
| **기업 CSR B2B** | 기업 사회공헌 담당 부서 | 기업이 이미 하고 있는 청소년 지원사업을 씨드온에 실어 실제로 닿게 하는 것. 운영비·후원 형태 |

**왜 이 둘인가**: 기관과 기업은 이미 청소년 지원에 예산을 쓰고 있는데 **그게 청소년에게
안 닿는 것이 그들의 문제**다. 씨드온이 푸는 문제가 곧 그들의 문제라서 값을 매길 수 있다.
청소년에게 과금하거나 광고를 붙이는 건 미션과 정면으로 충돌하므로 검토하지 않는다.

전략기획실(고문)은 수익·투자를 논할 때 **이 두 갈래를 전제로** 조언한다.

## 3-1. 이미 정해진 것 — 다시 묻지 말 것

로드가 이미 정한 것을 다음 날 또 물으면, 로드는 같은 판단을 두 번 하게 된다.
**정해진 건 여기 적고, 여기 있는 건 제안 목록에 올리지 않는다.**

| 언제 | 무엇을 | 어떻게 정해졌나 |
|---|---|---|
| 2026.08.16 | **기관에 직접 전화 거는 것 — 아직 안 한다** | 유입을 뚫는 게 급한 건 맞지만 지금 할 일이 아니다. 대신 **전략기획실이 고문 역할로 준비**한다. 실장이 이걸 두 번 다시 제안했고 로드가 두 번 다 잘랐다 |
| 2026.08.16 | 데일리 보고서는 **아티팩트로** | *"아티팩트에 올리면 바로 볼 수 있어서 괜찮아"* |
| 2026.08.16 | 지금 목표 수준은 **아이디어 경진대회 정도** | 그 이상(대규모 조직·본격 투자 라운드)은 지금 과하다 |
| 2026.08.16 | 수익은 **B2G · 기업 CSR B2B** 두 갈래 | 청소년 과금·광고는 검토하지 않는다 |

## 4. 이 회사에서 제일 중요한 규칙 셋

전부 `CLAUDE.md`에 있고, 어기면 서비스의 존재 이유가 무너진다.

**① 낙인 문구 금지.** "저소득층·취약계층·지원대상자·수급자"를 화면 어디에도 쓰지 않는다. 대외 문서(피칭·제안서)에서도 마찬가지다. "지원제도를 몰라서 못 쓰는 청소년"이라고 쓴다.

**② 중학생이 사전 없이 읽을 수 있어야 한다.** 낙인을 피하려다 행정용어("기준 중위소득 50%")로 도망간 적이 실제로 있다. 그건 낙인은 아니어도 청소년이 자기가 해당되는지 모르니 똑같이 실패다. 금액은 실제 돈으로 환산하고 "물어볼 곳"을 붙인다.

**③ 확인 못 한 숫자는 쓰지 않는다.** 금액·인원·기간은 **기관 자체 도메인에서 직접 본 것만.** 언론 보도·취합 사이트(위비티·링커리어) 숫자를 옮기지 말 것. 검색 결과 요약을 근거로 없는 사업·없는 금액을 올린 사고가 실제로 두 번 났다.

## 5. 우리가 실제로 겪은 사고 (같은 실수 반복 금지)

| 무슨 일 | 배운 것 |
|---|---|
| 검색 결과를 근거로 **없는 사업명·없는 금액**을 등록 | 사업명은 공식 페이지 그대로. 애칭·기사 제목을 사업명으로 쓰지 말 것 |
| 화면에 "씨드온이 소식을 챙겨드려요"라고 적었는데 **알림 기능이 없었음** | 화면이 약속한 것과 실제 기능이 맞는지 늘 확인 |
| 카톡 카드 로고를 **원본 크기로 보고** "괜찮다"고 네 번 답함 | 사용자가 실제로 보는 크기·기기로 확인할 것 |
| "우리 네트워크가 막혔다"고 로드에게 요청 → **기관 서버가 막는 것**이었음 | 결론 내리기 전에 진단부터. 로드에게 없는 숙제를 주지 말 것 |
| 부서 보고가 안 왔는데 **표를 채우려고 지어냄** (2026.08.16) | 못 받았으면 못 받았다고 쓴다. 빈칸이 거짓말보다 낫다 |

## 6. 부서가 일하는 방식

```
부서 → (근거와 함께) 보고 → 실장(병준)이 근거를 직접 확인 → 실장이 반영 → 로드에게 보고
```

**부서에게는 파일을 고치는 도구가 없다.** 일부러 안 줬다. 그래야 실장이 검수를 건너뛸 수 없다. "검수하겠다"는 다짐은 잊히지만 없는 권한은 잊히지 않는다.

**모든 부서가 지킬 것**
1. **확인한 것과 추측을 구분해서 보고한다.** "아마·일반적으로·~로 보인다"는 추측이다. 그렇게 적고, 무엇을 못 봤는지도 적는다
2. **근거 URL을 그대로 남긴다.** 요약만 주면 실장이 다시 찾아야 한다
3. **못 한 건 못 했다고 한다.** 빈손 보고가 그럴듯한 거짓 보고보다 낫다
4. **청소년 개인 사례를 지어내지 않는다.** 씨드온에는 아직 실제 사례가 없다
5. **볼 게 없으면 "없음"으로 짧게 끝낸다.** 억지로 일을 만들면 브리핑이 길어지고, 길어지면 로드가 안 읽는다
