## 이미 정해진 것 — 다시 묻지 말 것

로드가 이미 정한 것을 다음 날 또 물으면, 로드는 같은 판단을 두 번 하게 된다.
**정해진 건 여기 적고, 여기 있는 건 제안 목록에 올리지 않는다.**

| 언제 | 무엇을 | 어떻게 정해졌나 |
|---|---|---|
| 2026.08.16 | **기관에 직접 전화 거는 것 — 아직 안 한다** | 유입을 뚫는 게 급한 건 맞지만 지금 할 일이 아니다. 대신 **전략기획실이 고문 역할로 준비**한다. 실장이 이걸 두 번 다시 제안했고 로드가 두 번 다 잘랐다 |
| 2026.08.16 | 데일리 보고서는 **아티팩트로** | *"아티팩트에 올리면 바로 볼 수 있어서 괜찮아"* |
| 2026.08.16 | 지금 목표 수준은 **아이디어 경진대회 정도** | 그 이상(대규모 조직·본격 투자 라운드)은 지금 과하다 |
| 2026.08.16 | 수익은 **B2G · 기업 CSR B2B** 두 갈래 | 청소년 과금·광고는 검토하지 않는다 |
| 2026.08.17 | **관심 등록 기능은 없앴다** | 로드: *"북마크랑 관심프로그램이랑 겹치는 거 같음 — 관심 프로그램 삭제."* 화면만 걷어내고 `applications` 표와 로직은 되돌리기 쉽게 남겨뒀다. **"신청 폼이 없다"고 보고하지 말 것** — 없는 게 맞다 |
| 2026.08.17 | 데일리 자동 실행은 **지금 방에 묶는 방식** | "매 실행마다 새 세션"으로 하면 Supabase·GitHub·노션이 안 실려 데일리가 통째로 못 돈다 |
| 2026.08.18 | **「모두의 창업」 소셜벤처 리그는 안 낸다** | 마감이 하루 남았고, 심사 주제 다섯 중 "정보 비대칭 해소"에 맞는 게 없었다 |

## 우리가 실제로 겪은 사고 — 같은 실수 반복 금지

| 무슨 일 | 배운 것 |
|---|---|
| 검색 결과를 근거로 **없는 사업명·없는 금액**을 등록 | 사업명은 공식 페이지 그대로. 애칭·기사 제목을 사업명으로 쓰지 말 것 |
| 화면에 "씨드온이 소식을 챙겨드려요"라고 적었는데 **알림 기능이 없었음** | 화면이 약속한 것과 실제 기능이 맞는지 늘 확인 |
| 카톡 카드 로고를 **원본 크기로 보고** "괜찮다"고 네 번 답함 | 사용자가 실제로 보는 크기·기기로 확인할 것 |
| "우리 네트워크가 막혔다"고 로드에게 요청 → **기관 서버가 막는 것**이었음 | 결론 내리기 전에 진단부터. 로드에게 없는 숙제를 주지 말 것 |
| 부서 보고가 안 왔는데 **표를 채우려고 지어냄** (2026.08.16) | 못 받았으면 못 받았다고 쓴다. 빈칸이 거짓말보다 낫다 |
| 공식 도메인이라 믿고 올릴 뻔했는데 **그 페이지가 13년 전 글**이었음 (2026.08.18) | 출처가 공식인지만 보지 말고 **언제 쓰인 것인지**까지 본다. 3년 넘은 자료의 전화번호·주소·금액은 쓰지 않는다 |
| 전날 로드가 지시해서 뺀 기능을 **버그로 신고**함 (2026.08.18) | 부서 잘못이 아니라 알 방법을 안 줬던 것. 그래서 `docs/team-now.md`가 생겼다 — 일 시작 전에 반드시 읽는다 |

## 지금 진짜 막혀 있는 것

**제품이 아니라 유입이다.** 게시 42건, 링크 전부 살아 있고, 낙인 표현 0건인데
**가입자 0명 · 신청 0건**이다. 분자를 아무리 다듬어도 분모가 0이다.

기능을 더 만들어도 이 숫자는 안 움직인다. 그래서 팀마다 **"밖으로 나간 것"**을 매일 묻는다.

## 2026.08.19에 닫은 문

| 무엇 | 결론 | 왜 |
|---|---|---|
| **지역 한 곳을 정해 전수로 채우기** | **안 한다** | 로드 지적 — 씨드온은 지역 서비스가 아니다. 카드 42장 중 33장이 전국 대상이라 지역을 좁혀도 새로 채울 게 얼마 없고, 정보 비대칭을 없애자면서 한 구만 되게 만들면 미션에 어긋난다. 이건 "돈 버는 문제"의 답인데 지금 문제는 "아무도 모르는 문제"였다 |
