# 기관 명부 — 어디를 뒤질지 미리 정해둔 목록

> **왜 만들었나 (2026.08.18 로드 지시)**
>
> 로드: *"지원 프로그램을 먼저 찾는 것보다 일단 검색하는 기관들의 풀을 넓혀야 될 것
> 같아. 비영리단체나 소규모 단체 싹 다 리스트업을 해서 (…) 하루는 A카테고리 다음날은
> B카테고리 이런 식으로 훑는 건 어떨까?"*
>
> 지금까지는 **프로그램을 한 건씩 찾아다녔다.** 그래서 매일 "어디를 볼까"부터 다시
> 시작했고, 하루 종일 뒤지고도 0건인 날이 나왔다(2026.08.18 리서치 11건 발굴 → 0건 게시).
> 프로그램은 끝나면 사라지지만 **기관은 남는다.** 좋은 기관 하나를 찾아두면 해마다
> 공고가 나온다. 그래서 찾는 대상을 프로그램에서 **기관**으로 바꾼다.

## 지금 무엇이 비어 있나 (2026.08.18 실측)

게시 42건 중 **공공 27건(64%) · 비영리 15건(36%)**.
그런데 비영리 15건이 전부 **이름 아는 대형 재단**이다(굿네이버스·세이브더칠드런·
월드비전·초록우산·아름다운재단·삼성·KT&G·신한). **소규모 단체는 단 한 곳도 없다.**

로드 판단: *"공공기관 쪽으로는 연결이 애매하다."* 공공은 자격 심사·기관 경유가 많아
청소년이 오늘 할 수 있는 행동을 만들기 어렵다. 비영리·소규모는 직접 신청이 많고
청소년을 직접 만난다. **그래서 비영리·소규모를 집중해서 채운다.**

## 이 파일을 쓰는 법

**리서치팀**: 그날 칸의 표를 보고 `공고 게시판` 주소부터 연다. 표에 없는 기관을
새로 찾으면 보고에 적는다 — 실장이 여기 추가한다.

**실장**: 리서치가 새 기관을 가져오면 확인하고 표에 넣는다. 열어본 결과(`열림`/`막힘`)와
날짜를 같이 적는다. **그게 쌓여야 같은 곳을 두 번 헛되이 두드리지 않는다.**
