# 로드가 누른 건 성적표에서 빼기

로드(2026.08.19): *"나는 로그인을 하고 카드를 누를께. 내 아이디는 집계에 포함하지 않는 거를 할 수 있나?"*

**됩니다.** 빼야 할 게 둘이라 둘 다 막아뒀습니다.

| 무엇 | 어떻게 빠지나 |
|---|---|
| **로드가 누른 것** | 로그인하면 기록에 계정이 남아요. 그 계정에 "운영자" 표시를 켜두면 빠집니다 |
| **우리 점검 도구가 만든 것** | 기록에 "어디서 눌렸나"를 같이 남깁니다. 로컬에서 열린 건 빠집니다 |

## 로드 계정을 빼는 법 — 가입하신 다음에

**아직 못 켰습니다. 로드가 가입을 안 하셨거든요**(지금 가입자 0명).
가입하시면 아래 한 줄만 실행하면 됩니다.

Supabase → SQL Editor에서:

```sql
-- 로드 계정 찾기
select id, email from auth.users order by created_at desc;

-- 위에서 나온 id로 "운영자" 표시 켜기
update public.user_profiles set is_internal = true where user_id = '여기에-그-id';

-- 켜졌는지 확인
select user_id, is_internal from public.user_profiles where is_internal;
```

이거 켜고 나면 로드가 로그인한 채로 카드를 아무리 눌러도 관리자 화면 숫자는 안 올라갑니다.
**그게 정상입니다** — 그래야 그 숫자가 "밖에서 온 사람"만 세는 숫자가 됩니다.

## 로그아웃하고 누르면요?

**그때는 못 뺍니다.** 기록에 누구인지가 안 남으니까요.
그래서 로드가 *"로그인을 하고 카드를 누를께"*라고 하신 게 정확합니다. **꼭 로그인한 채로 봐주세요.**

(카드를 보는 데 로그인이 필요하지는 않습니다. 청소년은 로그인 없이도 봅니다.
그래서 로그인 안 한 기록은 "밖에서 온 사람"으로 셉니다.)

## 우리 점검 도구는 이미 빠집니다

`scripts/shot.mjs`로 화면을 찍으면 진짜 크롬이 뜨고, 그때 기록이 남을 수 있습니다.
이제 `localhost`에서 열린 건 "내부"로 표시돼서 집계에서 빠집니다.

**다만 지금 이 환경에서는 애초에 기록이 안 남습니다** — 화면 찍는 크롬이 바깥 인터넷에
못 나가서 데이터베이스까지 도달을 못 하거든요. 그래도 막아둔 이유는, 나중에 다른 데서
찍으면 그때는 남기 때문입니다.

## 지금까지 쌓인 7건은요?

**출처를 알 수 없어서 집계에서 뺐습니다.** `source = 'unknown'`으로 표시했어요.
로드가 폰으로 본 건지, 진짜 밖에서 온 사람인지 구분할 방법이 없습니다.
**추측해서 세는 것보다 안 세는 게 낫습니다.**

기록 자체는 안 지웠습니다. 나중에 필요하면 다시 볼 수 있어요.

## 세는 숫자가 뭔지

관리자 화면(`/admin`) 맨 위에 이렇게 뜹니다.

```
  1 / 42장     ← 올려둔 카드 중 기관 신청 페이지까지 넘어간 카드 수
  3 / 42장     ← 한 번이라도 열어본 카드
     39장      ← 아무도 안 열어본 카드
```

**카드는 계속 늘어나니까 비율보다 왼쪽 큰 숫자를 보세요.**
카드를 열심히 늘릴수록 비율(%)은 오히려 떨어집니다. 올라가야 하는 건 "닿은 카드 수"입니다.

**"아무도 안 열어본 카드" 목록은 리서치팀 작업거리입니다.** 아무도 안 누르는 카드는
문구가 안 와닿거나 엉뚱한 칸에 들어가 있을 수 있어요.

## 아직 확인 못 한 것

**로드 계정을 빼는 게 실제로 되는지는 못 봤습니다.** 계정이 하나도 없어서요.
데이터베이스에서 걸러내는 방식(뷰)은 시험해서 되는 걸 확인했지만,
**진짜 계정으로는 로드가 가입하신 뒤에 확인하겠습니다.**
