# 씨드온 앱 (뼈대)

웹 씨드온과 같은 카드를 폰 앱으로 보여주는 첫 뼈대입니다. 앱 스토어에는 아직 올리지 않습니다(로드 결정 2026.10.18 — 개발자 계정 없이 로드 폰에서 먼저 시연).

## 지금 되는 것
- 카드 목록 (웹과 같은 DB, 같은 순서 — 지금 열린 것 먼저, 마감 가까운 순)
- 검색 (이름·기관·설명·태그)
- 칸 고르기 (교육·심리상담·주거 …)
- 카드 열기 → 신청 방법, 단계, 신청 페이지 열기, 전화하기
- 못 불러오면 "다시 불러오기", 결과가 없으면 1388 안내

## 아직 안 넣은 것 (다음 단계)
로그인 · 저장 · 신청 · 알림 · 도우미. 폰에서 먼저 보고 붙입니다.

## 로드 폰에서 보는 법 (Expo Go)
컴퓨터 한 대와 폰 한 대가 필요합니다. 둘이 **같은 와이파이**에 있어야 합니다.

1. 폰에 **Expo Go** 앱을 설치합니다 (구글 플레이 / 앱스토어에서 "Expo Go" 검색, 무료).
2. 컴퓨터에 Node.js가 없으면 nodejs.org에서 LTS를 설치합니다.
3. 컴퓨터 터미널에서:
   ```
   git clone https://github.com/kisse1532-afk/seedon.git
   cd seedon/mobile
   npm install
   npx expo start
   ```
4. 화면에 QR 코드가 뜹니다.
   - 안드로이드: Expo Go 앱을 열고 "Scan QR code"로 찍습니다.
   - 아이폰: 기본 카메라로 찍으면 Expo Go로 열립니다.
5. 같은 와이파이가 아니면 `npx expo start --tunnel`로 다시 켭니다.

> Expo Go 앱 버전이 이 프로젝트의 Expo 버전(SDK 58)과 안 맞으면 "프로젝트가 호환되지 않아요"가 뜰 수 있습니다. 그때는 Expo Go를 최신으로 업데이트합니다.

## 개발 메모
- 스택: Expo SDK 58 · React Native · TypeScript · Supabase(공개용 publishable 키만)
- **service role(비밀) 키는 절대 앱에 넣지 않습니다.** 앱 파일은 누구나 풀어볼 수 있습니다.
- 웹(루트)과 따로 설치·검사합니다: `cd mobile && npx tsc --noEmit`
- 패키지 추가는 `npx expo install <이름>` (Expo 버전에 맞는 것을 골라줌)
- 문구 규칙은 루트 `CLAUDE.md` 절대규칙을 그대로 따릅니다 (낙인 문구 금지 · ~해요체 · 민감정보 안 물음 · 14세 이상).
